# MultiMod II Bootloader Notes
These files are part of a mkdocs markup document. To view the notes, run the following command in the Notes directory

mkdocs serve [>/dev/null 2>/dev/null]

The optional parameters in the brackets serve to divert status data from the server away from the console. Once the server has started, open the following URL in a browser of choice

https://127.0.0.1:8000/

For more information on mkdocs, including installation and use, see

https://www.mkdocs.org/getting-started/#installation
